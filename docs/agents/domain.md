# Domain docs

This repository uses a single domain context.

## Before exploring

- Read the root `CONTEXT.md` when it exists.
- Read relevant decisions under `docs/adr/`.
- If either location is absent, continue silently. Domain documentation is created only when a real term or
  decision needs to be recorded.

Use vocabulary from `CONTEXT.md` in issue titles, tests, design proposals, and implementation. Surface any
conflict with an existing ADR instead of silently overriding it.
